Add the experimental Continuo workspace mode: a folder-level agent that understands a folder on first open, keeps a correctable context ledger across tasks, verifies reported deliverables, and shows tasks on a board. Enable it with `KIMI_CODE_EXPERIMENTAL_CONTINUO=1` and run the `apps/continuo` front-end against `kimi web`.
